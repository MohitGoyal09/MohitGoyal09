## Research

### GRIT: Geometry-Aware PEFT with K-FAC Preconditioning, Fisher-Guided Reprojection, and Dynamic Rank Adaptation

[arXiv](https://arxiv.org/abs/2601.00231) · [Google Scholar](https://scholar.google.com/citations?view_op=view_citation&hl=en&user=wyomNxMAAAAJ&authuser=1&citation_for_view=wyomNxMAAAAJ:RGFaLdJalmkC)

Co-developed GRIT, a geometry-aware parameter-efficient fine-tuning method for LLM adaptation. My work included experiment design, benchmark evaluation, ablation analysis, and studying how K-FAC preconditioning, Fisher-guided reprojection, and dynamic rank adaptation affect adaptation efficiency and generalization.
